# SQL 草稿（預約流程改版 v2 第 2 階段）

這個資料夾裡的 6 份 SQL **都是草稿：沒有在任何資料庫執行過，也還沒做語法檢查。**

- 放在這裡而不是 `supabase/migrations/`，是為了不讓資料庫推送指令把它們當成正式 migration 執行。
- 每一份都要 terry 審閱同意後，由 terry 執行。執行順序、每份做什麼、怎麼還原：見 `../2026-11-26-booking-flow-v2-p2-sql-review.md`。
- 各組實作 PR 要用時，把對應的檔搬回 `supabase/migrations/`，並把檔名開頭的時間改成當時的時間（要排在已執行的 migration 之後）；檔頭的「草稿」字樣在 terry 執行後再改。
- 檔與檔之間的前後順序以審閱清單為準，不要只看檔名。
